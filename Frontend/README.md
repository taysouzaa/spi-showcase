# SPI Frontend

Frontend do SPI construído com React, TypeScript e Vite.

## Scripts
```bash
npm run dev
npm run build
```

## Configuração
Use `Frontend/.env`:

```env
VITE_API_URL=http://localhost:3333
VITE_DRIVE_FOLDER_URL=https://drive.google.com/drive/folders/...
```

## Estrutura
```text
src/
  app/
  features/
  shared/
  assets/
```
